AntiNuke Protection

Usage

antinuke enable

Default prefix is &

Requirements

  • Administrator permission
  • Bot role must be higher than moderator roles

Features

The following are FEATURES, not commands:

  • antikick
  • antiprune
  • channel / role / webhook protection
  • antibotadd
  • antiguild

Whitelist Suggestion

Use wl @user to whitelist users

note: must Whitelist from all events so that users are excluded from all AntiNuke events
